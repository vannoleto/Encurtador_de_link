# Encurtador de Links com Bitly API

## Descrição
Este é um projeto simples de encurtador de links utilizando a API do Bitly. O usuário insere uma URL longa, e o sistema retorna um link encurtado utilizando a API oficial do Bitly.

## Tecnologias Utilizadas
- HTML
- CSS (Bootstrap)
- JavaScript (Fetch API)
- API do Bitly

## Como Funciona
1. O usuário insere a URL desejada no campo de entrada.
2. Ao clicar no botão "Encurtar", o sistema faz uma requisição à API do Bitly.
3. O Bitly retorna um link encurtado, que é exibido no campo de resultado.

## Como Usar
### 1. Clonar o Repositório
```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
cd seu-repositorio
```

### 2. Editar o Arquivo `script.js`
No arquivo `script.js`, substitua `SEU_CODIGO_TOKEN` pelo seu token de acesso à API do Bitly.

### 3. Abrir o Arquivo `index.html`
Basta abrir o arquivo `index.html` em um navegador.

## Estrutura dos Arquivos
```
/
├── index.html  # Interface do usuário
├── script.js   # Lógica para encurtar o link
└── README.md   # Documentação do projeto
```

## Observações
- É necessário criar uma conta no Bitly para obter um token de acesso.
- Certifique-se de que a API do Bitly está funcionando corretamente ao testar o projeto.
